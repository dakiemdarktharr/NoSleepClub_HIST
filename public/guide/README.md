# Published reference photographs

The photographs are historical reference views, not live images or evidence of present-day access. The app hosts the Wikimedia thumbnail bytes without editing their image content. Browser training/prediction crops are derived from these public photographs only. No private-room recording or feature is included in the public classifier.

Attribution and licence links also appear in each stop's content. No endorsement by the photographers, historical sites or source publishers is implied.

`reference-model-v1.json` is generated by `scripts/build-tour-references.mjs`: three crops from each photo, nine feature supports, three classes labelled `tour:<siteId>`. DINOv2 is frozen; only the small few-shot classifier is fitted. Recognition still requires ORB/RANSAC evidence. The building-gate viewpoint, scaffolding, lighting or a different facade can yield an unknown result. No field accuracy is claimed from self-source regression tests.
