# HIST ornament sources

The four motifs were redesigned from a concept generated with the user-requested Canva plugin: [Open generated image](https://www.canva.com/M/MAHZUmAsJs0?utm_source=OC-AaBlKrqBJJNF&utm_campaign=agent_connector_create_image_asset_opened), Canva media `MAHZUmAsJs0`.

The committed SVGs are manual, simplified native-path recreations of that concept, **not SVG exports from Canva**. The connector supplied a raster concept preview. Paths were redrawn for small-screen legibility and editability: a temple-lintel dragon, ribbed lantern, river pavilion and lotus compass. No raster images are embedded.

Each file has an `artwork` group, a fixed viewBox and inherits `currentColor`. The app references that group using an SVG `use` element. Cinnabar details use `#8e3e34`. There are no scripts, external fonts or external image references. Decorative SVGs are hidden from screen readers; their enclosing controls have localized labels.
